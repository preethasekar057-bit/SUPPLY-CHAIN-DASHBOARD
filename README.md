# SUPPLY-CHAIN-DASHBOARD
This Power BI Supply Chain Dashboard shows important details like revenue, shipping cost, defect rate, transportation, and delivery time. It helps users easily understand supply chain performance, compare different locations and transport methods, and find useful information for better business decisions.
# 🚚 Supply Chain Dashboard

## 📊 Project Overview

This project is a **Supply Chain Dashboard created using Power BI**.  
The dashboard helps to understand supply chain performance, costs, transportation, and delivery information.

## 🎯 Key Features

- Total Revenue
- Shipping Cost
- Defect Rate
- Lead Time
- Transportation Mode
- Location-wise Performance
- Product-wise Analysis
- Supply Chain Performance

## 🛠️ Tools Used

- Power BI
- Data Visualization
- Data Analysis
- Power Query
- DAX

## 📈 Dashboard

The dashboard provides a simple view of supply chain performance and helps identify important trends in revenue, shipping costs, transportation, delivery time, and defects.
